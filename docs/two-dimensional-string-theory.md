by Emil J. Martinec (hep-th/0410136, 55 pages, 15 figures)

[Matrix Quantum Mechanics and Two-dimensional String Theory in Non-trivial Backgrounds](http://arxiv.org/abs/hep-th/0311273)  
by Sergei Alexandrov (hep-th/0311273, 177 pages)

[Topological Matrix Models, Liouville Matrix Model and c=1 String Theory](http://arxiv.org/abs/hep-th/0310287)  
by Sunil Mukhi (hep-th/0310287, 35 pages)

[Lectures on 2D gravity and 2D string theory. ](http://arxiv.org/abs/hep-th/9304011)

[String Theory in Two Dimensions](http://arxiv.org/abs/hep-th/9108019)

### papers
[D-brane decay in two-dimensional string theory](http://arxiv.org/abs/hep-th/0305159)  
by I.R. Klebanov, J. Maldacena, and N. Seiberg (hep-th/0305159, 19 pages)  
This paper provides a useful description of the modern perspective on c=1 matrix
models and their connection to D0-branes and gauge/gravity duality.
