# References with BiBTeX

In standard LaTeX you can use the <code>\thebibliography</code> environment and <code>\bibitem</code>'s to list your references within the file.  If you have several documents with similar references this becomes tedious.  BiBTeX allows you to create a single database of references and then finely control the style in which they are displayed.

### links
[LaTeX Tricks: BiBTeX](http://www.iam.ubc.ca/~newbury/tex/bibtex.html)

[BibTeX Style Examples](http://www.cs.stir.ac.uk/~kjt/software/latex/showbst.html)

[SPIRES](http://www.slac.stanford.edu/spires/)
