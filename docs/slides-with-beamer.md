# Slides with beamer

[beamer](http://latex-beamer.sourceforge.net/) is a LaTeX class for creating presentations.

Often it must be installed separately from LaTeX.  For Debian-based GNU/Linux systems such as [Ubuntu](http://www.ubuntulinux.org/) install the <code>latex-beamer</code> package.
