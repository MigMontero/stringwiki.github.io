# D branes

see also [Branes](branes.md), [The AdS/CFT correspondence](the-ads-cft-correspondence.md)

### books
**D-Branes**  
by Clifford Johnson (CUP, 2003)  
This begins with a pedagogical quantization of a
single string and moves on to address many modern topics such as
fractional branes, the enhancon mechanism, and dielectric branes.
